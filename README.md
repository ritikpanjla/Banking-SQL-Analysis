# Banking-SQL-Analysis

This project analyzes a banking dataset using MySQL to understand
customer behaviour, account ownership, loan portfolio and regional
business patterns.

## Objectives

- Perform basic data quality checks
- Analyze customer distribution
- Analyze account ownership
- Analyze loan portfolio
- Compare regional performance
- Generate business-oriented insights

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Analysis Performed

1. Data Overview
2. Data Cleaning
3. Customer Analytics
4. Account Analytics
5. Loan Analytics
6. Regional Analysis
7. Business Insights

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- Aggregate Functions
- Subqueries
- COUNT
- SUM
- AVG
- MAX
- MIN
- DISTINCT

## Key Insights

- Analyzed the overall customer, account and loan portfolio.
- Identified customers with multiple accounts.
- Identified customers without loans for potential cross-selling analysis.
- Analyzed loan distribution and loan exposure by status.
- Compared customers, accounts and loan exposure across regions.
